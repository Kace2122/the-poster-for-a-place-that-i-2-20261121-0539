SOLMARA — a vintage art-deco travel poster for an invented coastal city where two suns set through a great natural stone arch over a violet sea. The program writes the poster to `/output/entry.png` for make.fun's "The Poster for a Place That Isn't There" bounty.

## Run it

```sh
python3 main.py
```

The poster is written to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set). Standard library only, no network, deterministic: every run writes the same bytes.
